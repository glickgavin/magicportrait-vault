# My Magic Portraits

The signed-in customer area at **my.magicportraits.ai** (internal code name "vault"):
- free greeting cards made from customers' own portraits
- every portrait, ordered or not
- orders, downloads and the free mug
- Settings for super users.

Start with **`SPEC.md`**, the master spec. `BUILD.md` has the set-up checklist and the one prompt that builds the app with Claude Code. `CLAUDE.md` holds Claude Code's standing rules. `docs/` and `designs/` hold the detail: data sources, schema, analytics, design tokens and the approved screens.
