Theme artwork spec

Each theme version is up to two image files plus a layout set in the admin. The system adds the portrait and the text, then exports the JPEG.

Rules of thumb

  • Why two files: JPEG keeps full-colour art small; transparency needs PNG, so overlays are always PNG.
  • Simplest theme: one background JPEG, no overlay.
  • Category: each theme sits in one of Holidays, New Year, Birthdays or General, set in the admin.
  • Template: a 1500 × 2100 Canva, Figma or Photoshop file with guide layers for the safe area, photo zone and text zones.
  • File names: christmas-snowfall-background.jpg and christmas-snowfall-overlay.png.
  • Output: JPEG 1500 × 2100 to download and share; 750 × 1050 inside emails.
